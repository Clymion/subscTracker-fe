# Product Overview

サブスクリプション管理アプリ（Subscription Management App）- 定期購読サービスの支払いを一元管理するWebアプリケーション

## Core Capabilities

- **サブスクリプション管理**: 定期支払いの登録・編集・削除・一覧表示
- **支払履歴**: 過去の支払い記録の追跡と確認
- **為替対応**: 複数通貨での登録とユーザー設定通貨への自動換算
- **ラベル管理**: サービスをタグ付けで分類・フィルタリング

## Target Use Cases

- 複数のサブスクリプションを契約し、月額/年額コストを把握したいユーザー
- 外貨建てサービスの料金を日本円等の基軸通貨で管理したいユーザー
- 次回支払日の把握と支払いスケジュールの可視化

## Value Proposition

- **一元管理**: 散在する定期支払いをダッシュボードで可視化
- **通貨換算**: 為替レートを考慮した実質コストの把握
- **モバイル対応**: レスポンシブデザインでスマートフォンからも利用可能
